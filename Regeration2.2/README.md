# HIT140 Assessment 3 – Regression 2.2

## About the Project

For Regression 2.2, our group used Python to predict the number of goals scored by a team in a FIFA World Cup 2026 match.

We used a dataset containing 208 rows from 104 matches. Each match has two rows because we are predicting the goals scored by each team separately.

We used eight explanatory variables to make the predictions. These include FIFA rankings, Elo ratings and information from previous matches. All the variables were based on information available before the match started.

Linear regression was our main method, as required for the assessment. We also tested other models to compare their prediction accuracy.

## What We Did

### 1. Exploring the Dataset

We started by exploring the dataset to understand the information we were working with.

We checked the relationships between different variables and looked at how FIFA rankings and team strength were related to goals scored.

We also examined correlations between variables. For example, FIFA rankings and Elo ratings both measure team strength, so they may contain similar information.

This helped us understand the dataset before building our prediction models.

### 2. Building the Models

We started with Ordinary Least Squares (OLS) linear regression.

We then tested Ridge regression, including versions using log-transformed FIFA rankings. Ridge regression was useful because some of our explanatory variables contained similar information.

We also compared our linear regression models with:

- Poisson regression
- Random Forest
- Gradient Boosting

A simple model that predicts the average number of goals was included as a baseline for comparison.

Ridge regression with log-transformed FIFA rankings was the reported linear model in our analysis.

### 3. Testing the Models

We divided the dataset based on match dates.

The first 83 matches were used to develop and compare the models. We used four expanding-window cross-validation folds, where models were trained using earlier matches and validated using later matches.

The final 21 matches, played between 2 July and 19 July 2026, were kept for final testing.

We also made sure that both teams from the same match stayed in the same group when splitting the dataset.

To compare model performance, we used three main measures:

- **MAE (Mean Absolute Error):** Measures the average difference between predicted and actual goals. Lower values are better.
- **RMSE (Root Mean Squared Error):** Similar to MAE, but gives more importance to larger prediction errors. Lower values are better.
- **R² (R-squared):** Measures how much of the variation in goals scored is explained by the model. Higher values are generally better.

We compared the results with the baseline model to see whether our regression models provided better predictions.

### 4. Comparing Different Variables

We also tested whether using different groups of variables affected prediction accuracy.

We compared three groups:

1. All eight explanatory variables.
2. Four variables shared with Regression 2.1.
3. Four variables specific to Regression 2.2.

The results of this comparison are saved in `feature_set_ablation.csv`.

## Data Sources

We prepared our dataset using the following sources:

- **FIFA rankings:** FIFA/Coca-Cola Men's World Ranking released on 11 June 2026.
- **Elo ratings:** World Football Elo Ratings (https://www.eloratings.net), using ratings from 10 June 2026, before the tournament.
- **Match results and dates:** International football results dataset (https://github.com/martj42/international_results), commit `a16ff3e`, dated 20 July 2026.
- **Rest days and matches played:** Calculated from match dates using only earlier matches.

The goals scored include extra time but do not include penalty shoot-outs.

We used pre-tournament FIFA rankings and Elo ratings so that the models would not use information from World Cup results to predict those same matches.

## Limitations

There are some limitations to our analysis.

We only used data from one World Cup tournament, so the results may not be the same for other competitions.

FIFA rankings and Elo ratings also contain similar information, which can make it difficult to understand the effect of each variable separately.

Football results depend on other factors, such as injuries, tactics and unexpected events during matches, which are not fully represented in our dataset.

Our analysis uses historical match results, so we cannot assume the models will achieve the same accuracy when predicting future matches.
